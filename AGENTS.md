PromoPower Website Project

Project Context

This repository contains the PromoPower website redesign and enhancement project.

The objective is to evolve the current website into a professional, trustworthy and conversion-focused digital presence that reflects PromoPower’s experience, operational excellence and long-standing reputation in providing staffing solutions for promotions, retail activations, customer engagement programmes and events.

This is an enhancement project.

It is not a redesign project.

The current website already contains strong visual foundations, a modern design language and a high-quality user experience. The goal is to strengthen content, trust signals, information architecture and conversion flow while preserving existing strengths.

Non-Negotiable Rules

Do not redesign the website from scratch.

Do not replace the design system.

Do not introduce new frameworks without approval.

Do not replace existing architecture unless technically necessary.

Do not remove existing functionality unless approved.

Do not create duplicate components when reusable components already exist.

Do not change implementation patterns without understanding the existing architecture.

⸻

Content Rules

Use approved content from the project documentation.

Do not replace approved copy with AI-generated alternatives.

Do not shorten approved copy without a clear reason.

Do not introduce generic agency language.

Do not introduce startup-style marketing language.

Do not introduce hype-driven copy.

Content should reflect:

* Experience
* Professionalism
* Reliability
* Operational excellence
* Customer focus

Responsive Requirements

* Tablet
* Mobile

Accessibility Requirements

Maintain or improve accessibility.

Requirements:

* Semantic HTML
* Proper heading structure
* Keyboard navigation
* Screen reader support
* Focus states
* Colour contrast compliance
* Accessible forms

Accessibility must never be sacrificed for aesthetics.

⸻

SEO Requirements

* Metadata
* Internal linking
* Structured headings
* Semantic markup

Enhance:

* Content depth
* Search relevance
* Information hierarchy

Performance Requirements

* Unoptimised assets
