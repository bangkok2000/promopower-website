Objective

Implement the approved PromoPower website enhancements using the project documentation as the single source of truth.

This is an enhancement project.

It is not a redesign project.

The current website already contains strong visual foundations, modern UX patterns and a functioning technical architecture.

The objective is to strengthen:

* Trust
* Credibility
* Professional positioning
* Information architecture
* Conversion flow
* Content quality
* SEO
* Accessibility

while preserving existing strengths.
